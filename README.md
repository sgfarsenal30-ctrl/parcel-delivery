# parcel-delivery

# What is the purpose of this project?
This project is a support pillar in delivering personal parcels to their designated destinations with no damage and inconvenience. 

# Why?
We created this project to help people better understand the process, avoid common delivery problems and learn how to ensure their packages arrive safely.

# How?
The project provides information about the process of parcel delivery along with resources. It guides customers through the delivery process, explains delivery update and provides advice on handling problems.
